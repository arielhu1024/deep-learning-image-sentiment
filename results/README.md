# Results

This folder contains summarized model performance and engagement analysis outputs.

- `model_performance_summary.csv`: Overall comparison across all deep learning models.
- `binary_classification_results.csv`: Precision, recall, F1-score, and support for binary classifiers.
- `multiclass_classification_results.csv`: Precision, recall, F1-score, and support for multi-class classifiers.
- `engagement_analysis_results.csv`: Summary of engagement prediction results.
